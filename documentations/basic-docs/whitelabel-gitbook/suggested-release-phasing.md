## 29. Suggested Release Phasing

### Phase 1 — Web Branding Foundation

- Branding add-on entitlement.
- Locked/unlocked state.
- Whitelabel list.
- Create/edit/view whitelabel.
- Brand Setup.
- Authentication method configuration.
- Primary colour and generated UI roles.
- Runtime-supported mobile theme-token sync.
- Domain list and basic domain status.
- Publish/fallback/audit basics.

### Phase 2 — Self-Serve Customer Workflow and Mobile Tracking

- Client-side Settings → Branding entry point.
- Purchase flow handoff from Branding page.
- App package selection: Web, Android, iOS or Both.
- Android app build status tracking.
- Client approval/rejection with comments.
- Build history and estimated delivery date.
- Internal notifications or ticketing integration.

### Phase 3 — Advanced Branding

- Custom login page configuration.
- Logo colour extraction and automatic palette generation.
- Email branding templates.
- Custom sender/domain verification.
- iOS app build tracking.
- Rollback and version comparison.
- Deeper app-store/mobile identity support.
