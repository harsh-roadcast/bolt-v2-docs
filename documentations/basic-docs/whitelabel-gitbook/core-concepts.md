## 8. Core Concepts

| Concept | Definition |
| --- | --- |
| Whitelabel | A brand configuration linked to an organisation. |
| Brand Setup | Core brand identity, company details, legal links and app distribution data. |
| Authentication / Login & Experience | Login method and authentication experience used by the whitelabel. |
| Theme | Colour system and UI token configuration applied to the web and runtime-supported mobile experience. |
| Advanced Controls | Domain and higher-risk configuration controls. |
| Published Config | Branding configuration currently active for end users. |
| Draft Config | Unpublished changes being configured or reviewed. |
| App Build | Android/iOS branded app delivery artifact or delivery status. |
| Mobile Runtime Theme | Mobile-app theme state fetched from the published Branding configuration without requiring a new app-store build. |
| Brand Entitlement | Subscription/add-on state that controls whether branding is available for the organisation. |
