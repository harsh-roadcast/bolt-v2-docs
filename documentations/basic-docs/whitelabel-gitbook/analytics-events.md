## 25. Analytics Events

| Event | Trigger |
| --- | --- |
| `branding_locked_viewed` | User views locked branding page. |
| `branding_unlock_clicked` | User clicks unlock/purchase CTA. |
| `branding_purchase_started` | Purchase flow starts from branding. |
| `branding_config_opened` | User opens Branding/Whitelabel Manager. |
| `branding_create_started` | User starts create flow. |
| `branding_brand_setup_saved` | Brand Setup step saved. |
| `branding_logo_uploaded` | Logo uploaded successfully. |
| `branding_auth_saved` | Authentication step saved. |
| `branding_theme_saved` | Theme step saved. |
| `branding_color_changed` | Primary colour changed. |
| `branding_mobile_theme_sync_started` | Mobile theme sync begins after publish or app config fetch. |
| `branding_mobile_theme_sync_success` | Mobile app applies published branding tokens successfully. |
| `branding_mobile_theme_sync_failed` | Mobile app fails to apply published branding and falls back. |
| `branding_domain_added` | Domain added. |
| `branding_domain_verified` | Domain verification succeeds. |
| `branding_publish_clicked` | User attempts to publish. |
| `branding_publish_success` | Publish succeeds. |
| `branding_publish_failed` | Publish fails. |
| `branding_mobile_build_initiated` | Mobile build workflow starts. |
| `branding_mobile_build_approved` | Client approves build. |
| `branding_mobile_build_rejected` | Client rejects build. |
| `branding_rollback_clicked` | Rollback initiated. |
