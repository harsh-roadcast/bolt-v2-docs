## 24. Security, Privacy and Compliance

- Only authorised users can configure branding.
- Domain verification must prevent domain takeover.
- Uploaded assets must be scanned and stored securely.
- Published branding changes must be logged.
- Legal URLs should be visible in relevant customer-facing surfaces.
- Email sender/domain verification should follow SPF/DKIM/DMARC requirements if custom sender is supported.
- Super Admin override should be audited.
- Impersonation-based setup must record the acting internal user and target customer organisation.
