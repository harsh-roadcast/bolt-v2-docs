## 28. Open Decisions

| Is the first release client-side self-serve, Admin-side only, or both? | Product | The current approved interface is Admin-side; the product direction includes client self-service. |
| What exactly is included in the paid add-on: Web, Android, iOS or bundle? | Product / Business | Commercial packaging varies by customer requirement. |
| Should web branding publish immediately or require explicit Publish? | Product / Engineering | The final save-versus-publish interaction remains to be confirmed. |

| What is the exact mobile build SLA? | Ops / Engineering | The current operational estimate is approximately seven days. |
| Can clients approve/reject builds directly in Bolt? | Product | The proposed workflow supports this. |
| Should colour auto-extraction from logo be Phase 1 or later? | Design / Engineering | The proposed workflow suggests extracting colour from the logo. |
| Should support/admin be allowed to impersonate customer for setup? | Product / Security | The operational workflow treats this as a fallback. |
| Is custom login page background/image/text Phase 1 or Phase 2? | Product | The current roadmap places this in Phase 2 or later. |
| Which exact mobile screens and components support runtime branding in Phase 1? | Product / Mobile Engineering / Design | Required to define first-release mobile theme coverage. |
| What is the mobile branding config refresh policy? | Mobile Engineering | Options include login, app foreground, manual refresh or periodic fetch. |
