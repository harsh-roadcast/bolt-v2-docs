# White Label Branding

## 1. Overview

White Label Branding is a paid Bolt v2 module that enables a customer, reseller or authorised admin to configure brand identity for the Bolt platform without depending on one-off Super Admin or developer-led customisation.

The module converts the existing manual white-label process into a productised workflow where customers can purchase branding, configure core brand details, manage login experience, manage theme colours, manage domains and track mobile-app white-label delivery where applicable.

A key product requirement is that theme values configured in the web Branding Module must reflect inside the Bolt mobile app wherever runtime theming is supported. Runtime-supported mobile theme changes should not require a new app build. Changes that alter store identity, launcher assets, package/bundle identity or bundled app assets continue to follow the mobile build workflow.

The long-term goal is a client-facing self-serve Branding Module. The approved Admin Whitelabel interface defines the current field structure and management workflows. The broader product workflow defines purchase, mobile delivery, approval, versioning, and operational handoffs.
