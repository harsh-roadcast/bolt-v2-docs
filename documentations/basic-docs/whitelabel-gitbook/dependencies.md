## 27. Dependencies

| Dependency | Why It Matters |
| --- | --- |
| Plan, Billing and Add-ons | Branding is a paid add-on. |
| RBAC | Controls who can view, edit, publish and approve. |
| Frontend theming system | Applies colour and asset tokens to web app. |
| Mobile runtime theming/config fetch | Applies supported published theme tokens inside the Bolt mobile app without requiring a new build. |
| Asset storage/CDN | Stores logos, favicon and build assets. |
| Domain mapping infrastructure | Supports CNAME/TXT verification and SSL. |
| Email service | Supports branded sender and templates. |
| Mobile release workflow | Required for Android/iOS branded builds. |
| Notification / ticketing system | Required for support/developer handoffs and build approvals. |
| Audit logging | Required for compliance and rollback. |
