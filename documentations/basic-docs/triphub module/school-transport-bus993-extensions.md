## School Transport / Bus993 Extensions

School Transport extends the base target-route-trip model.

### User-to-target mapping

Support many-to-many mapping:

- Parent to multiple students.
- Student to multiple guardians.
- Attendee to assigned route/trip.

### Parent access

Parent/guardian users can view only:

- Linked students.
- Assigned routes/trips.
- Bus location for active trip.
- Pickup/drop state.
- ETA where available.

### Student tracking

Supported states:

- Pickup pending.
- Picked up.
- Drop pending.
- Dropped.
- Missed pickup/drop.
- Manual override.

### Boarding/deboarding

Phase 1:

- Manual marking.

Phase 2:

- Facial Recognition based marking.

Fallback:

- Manual override with reason.
